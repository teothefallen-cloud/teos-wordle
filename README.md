# Words by Teo
A modern, endless reimagining of the classic Wordle game, built entirely from scratch to provide a native experience for the Italian-speaking community.  Unlike the original version which offers only one daily puzzle, Teo's Wordle introduces a progressive and continuous gameplay mode designed for endless, competitive fun.
All the credits of the game go to New York Times who made the original Worldle, I've just worked on it using an entire code made by me
